# 📚 Student Resource Management Platform
A centralized academic productivity platform designed to help students access syllabus materials, previous exam papers, and manage study workflows efficiently through a structured and responsive interface.

## 🚀 Overview
Students often struggle to locate academic resources scattered across multiple sources. This platform provides a single unified interface for accessing study materials and tracking preparation progress.

The system improves:

* Resource discoverability
* Study planning efficiency
* Academic workflow organization
* Cross-device accessibility
* 
## ✨ Key Features

* Centralized access to syllabus and previous year question papers
* Fully responsive UI supporting mobile, tablet, and desktop devices
* Built-in task tracking module for study scheduling
* Structured navigation for faster academic content discovery
* Lightweight browser-based deployment for easy accessibility
